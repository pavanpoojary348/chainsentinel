# 🚀 ChainSentinel — 1-Minute Quickstart Guide
**IBM Z Datathon 2026 | Team PingXero**

> ChainSentinel is a multi-agent, closed-loop AI supply chain resilience platform built for **IBM LinuxONE (s390x)** and **Db2 for z/OS**.

---

## ⚡ Option 1: 1-Click Launch on IBM LinuxONE / Linux / Mac

In your terminal:
```bash
bash start.sh
```
*What this does automatically:*
1. Detects Python 3 & virtual environment.
2. Verifies dependencies and runs all ML & API integrity tests.
3. Launches the web app on `http://0.0.0.0:8000` (accessible from laptops & smartphones).

---

## ⚡ Option 2: 1-Click Launch on Windows

Simply double-click **`start.bat`** (or run `start.bat` in Command Prompt / PowerShell). It opens `http://localhost:8000` directly in your browser.

---

## ⚡ Option 3: Run the Native IBM LinuxONE Jupyter Notebook

1. Open JupyterLab on the IBM LinuxONE server:
   `http://148.100.109.180:38888/notebooks/chainsentinel/ChainSentinel_IBM_Z_Demo.ipynb`
